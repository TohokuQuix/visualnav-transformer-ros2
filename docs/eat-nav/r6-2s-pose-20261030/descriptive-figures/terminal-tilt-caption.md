# 転倒終端3例の姿勢・予測・STOP要求

PNG/PDFは、未完了validationから選んだ3失敗例を示します。青線は20Hz実測の重力基準合成傾斜、橙点は判断時点で予測した次の2秒の最大傾斜です。橙点は現在姿勢の予測ではありません。赤破線は85度の実測転倒基準、灰色は保護STOPの要求区間です。

灰色はActor入力の即時ゼロや物理的な静止を表しません。既存の固定制御は `actor_seen = target + alpha*(previous_raw-target)` の指令遅延補間を行い、STOP移行最初の50ms制御区間には前指令の混合が残ることがあります。確認した3例では計7区間が該当し、q1_1/group000は4区間（alpha0.7）、q0_2/group018は3区間（alpha0.4）、q1_1/group004は0区間でした。これは丸ごと50msの純遅延という意味ではありません。

集計のprotective_stop_secはSTOP要求時間です。Actor入力ゼロ時間、モータ出力ゼロ時間、機体の静止時間へ読み替えないでください。q0_2の別診断で記録した9.4秒は、この移行1区間を除いた連続Actorゼロ指令区間なので、その測定は変更しません。
