# MI-A v3.1 seed-range correction and smoke protocol

MI-A v3 failed before environment construction because its terrain seed exceeded `2**32-1`. The v3 manifest, source, failed evidence and seals remain unchanged on branch `exp/eatnav-mi-a-v3`. This v3.1 series changes only the 12 terrain seed values and adds prelaunch `0 <= seed <= 2**32-1` validation. All terrain types, levels, postures, candidates, 192-row assignment structure, Gate P, thresholds, controller, Actor, Path Bank, physics and resource caps are identical to v3.

The reproducible seed formula is `terrain_seed = 2026101401 + 100*terrain_index + (terrain_level-1)`, with terrain indices in the ordered list `pyramid_stairs`, `pyramid_stairs_inv`, `random_rough`, `k_rail_step_field` and levels 1, 2, 3. The resulting distinct seeds are `2026101401–2026101403`, `2026101501–2026101503`, `2026101601–2026101603`, and `2026101701–2026101703`. These values are within NumPy's unsigned 32-bit seed range. The collection allocation is regenerated deterministically with the unchanged randomization seed `2026101403` and the new StateGroup IDs; its behavior remains Front/Rear 50:50 at StateGroup granularity. DEMO remains Front-folded fixed.

This series is separate from B-R0/B-R1, MI-A v1/v2 and MI-FI v1. The original MI-FI simulator, host, Gate P implementation, frozen Path Bank, Actor checkpoint, noise/latency, 20-step settling, 20 Hz control, 40-step (2 s) labels and resource caps are reused without numeric changes. New results never revise historical seals or decisions.

## Modes and StateGroups

`demo` uses front-folded `[RR,RL,FR,FL]=[0,0,π,π]` and fold mode 0 at every reset. It does not read a collection assignment. `collection` requires a frozen StateGroup allocation: seeded SHA-256 ordering within each terrain stratum, alternating Front/Rear, with the odd extra assignment alternating by terrain. All Paths of one StateGroup share that allocation. `evaluation` requires an explicit manifest assignment and measures **both** postures on the same terrain seed and four env tiles. The initial posture is metadata; the Motion Predictor should use measured Actor state, not a privileged posture label. No collection rollout is part of this protocol.

The assignment has four terrain types (`pyramid_stairs`, `pyramid_stairs_inv`, `random_rough`, `k_rail_step_field`), three distinct terrain seeds per type at levels 1, 2, 3, and four env tiles per process. There are 12 independent terrain seeds, 24 posture-conditioned StateGroups, 192 sequential processes (48 pre-Path, 144 candidate), and 576 candidate trials. Env tiles share a terrain seed and are paired replicates, never 576 independent conditions. The initial smoke comprises the first `pyramid_stairs` and first `k_rail_step_field` seed, both postures and all six candidates: 32 processes / 96 candidate trials. Successful sealed smoke attempts are reused read-only in formal continuation.

Each posture/seed runs two fresh-process candidate-free pre-Path captures followed by Forward Direct/+30°/−30° and Reverse Direct/+30°/−30°. The first candidate-free record is the sealed Gate P reference. Gate P at its existing 1e−6 threshold compares all visible state/Actor/DEM/contact/Critic/noise/delay/RNG/controller fields *within* one posture and seed. Different postures need not have equal settled root/contact state. Mirror asymmetry is diagnostic only. Same-episode, finite arrays, expected shape, fold mode 0, joint pose and limits, terminal state, resource, native exit, inner/outer SHA and seal must pass. A violation stops the schedule; no automatic retry. Each attempt has a unique root and is verified before the next.

## Primary analysis frozen before runtime

For each env tile and posture, Arc minus same-direction Direct uses initial-body-frame `(Δx,Δy,wrapped Δyaw)`. Reverse Δx remains signed. Each seed is first averaged across its four env tiles. For each candidate and posture, report each seed mean, each terrain mean, the 12-seed mean vector and a terrain-stratified seed bootstrap (10,000 draws, RNG seed 2026101403) 95% interval on projected XY effect and yaw. The XY projection uses the observed grand-mean direction, so this is an exploratory directional interval and does not establish a population-wide detection guarantee. Report Front/Rear interaction as Rear minus Front Arc-relative effect on the same seed/tile. Report pitch/roll, flipper joint and torque, contact, command, sprocket velocity and termination as diagnostics from traces; do not reinterpret ideal yaw sign or left/right symmetry as protocol gates.

Primary effect threshold is 0.03 m in 2 s, inherited from MI-A v2. A candidate/posture is descriptively identifiable if the projected XY 95% lower interval exceeds 0.03 m and at least 9/12 independent seed effects have XY norm above 0.03 m. MI-A Pass requires at least one Forward and one Reverse candidate/posture to satisfy this; Fail requires every candidate/posture upper interval below 0.03 m; otherwise Inconclusive. Candidate-level classifications and posture interaction are reported separately. These are fixed exploratory criteria, not a claim of statistical generalization to unseen terrain types. Insufficient independent seeds or any missing/invalid process yields Inconclusive or protocol stop, never imputed data.

## Execution gates

Stage 0 source/config and historical evidence audit; Stage 1 seed-range RED→GREEN tests; Stage 2 unchanged DEMO static/unit non-regression; Stage 3 v3.1 manifest/source SHA freeze; Stage 4a one candidate-free first-seed Front-folded pre-Path capture, with a complete finite four-env snapshot and verified seal; Stage 4b a 32-process, two-seed multi-terrain smoke only if 4a passes. The sealed 4a process is reused read-only as row 0 of smoke. Any preflight/smoke protocol or resource failure stops without automatic retry. **The 192-process formal run is not authorized in this revision.** No ±60°/±90°, Motion Predictor training, Goal-selection evaluation or full collection.
