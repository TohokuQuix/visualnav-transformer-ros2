# Geometry-only proposal if current support is insufficient

This is a proposal for a later, separately approved collection. It does not change the present 28 StateGroups, model comparison, or any saved Outcome.

The frozen C1 audit found 15 flat, 12 transition, one differential, and zero common-rough StateGroups. Twenty-six of 28 groups formed one connected corridor cluster across all seven candidate Paths under the frozen 0.03 m pair-RMS rule. The two groups with multiple clusters are left/right goals from the same source anchor (`indep-train-006`), so there is only one independent anchor family with distinct corridor geometry. The differential stratum has fewer than the preregistered three StateGroups needed for a performance claim.

For a future pool, select candidate start states using only DEM and Path geometry before any rollout or Outcome is visible. Keep the current 16×7 corridor, 0.1 m resolution, 0.03 m numeric-equivalence threshold, and 50% minimum valid fraction. Seek at least three independent StateGroups per differential and transition stratum, with more than one distinct corridor cluster in each selected group. Record the full terrain-type and terrain-seed distribution; avoid concentrating all selected states near flat tile centers. Use independent source trajectories and episode identities, and preserve every seven-candidate group intact across splits.

This proposal does not authorize collection, change thresholds, or alter the current experiment's support classification.
