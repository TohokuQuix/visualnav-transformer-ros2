# Future Evaluator training plan and gates

This is a prospective plan. No training or validation was run for this review.

1. **Input readiness:** establish robot/simulator parity for DEM axis/resolution/unknown mask, IMU extrinsic and clock, base linear velocity, all 52 ordered joints, and previous ActionManager action. Verify that every primary field is captured before Path publication. Missing critical fields force abstention. Compare logging enabled/disabled duplicate runs before collecting labels.
2. **Label readiness:** acquire more independent StateGroups and diverse difficulty, goal, terrain, command, candidate and endpoint-encounter outcomes. Preserve raw per-step reward components and the existing total reward with once-only `dt` scaling; pre/post command-update stamps and terminal pre-reset Critic inputs; verified physical terminations and censor reasons. No inferred reward components or pseudo Safety positives.
3. **Split gate:** split by StateGroup and source trajectory/environment instance/terrain seed before fitting any scaler. Keep every candidate and duplicate from one group in one split. Set validation and held-out support before any model or weight selection. Save split group IDs and hashes.
4. **Phase A smoke:** run a tiny overfit and shape/mask test for each primary regression head and strict-pair loss. Confirm tie/invalid masks cause zero gradient, no pair crosses groups, and the output/normalization metadata match the frozen schema. Compare against direct prediction and constant/group-prior baselines. This is a software gate, not an effectiveness claim.
5. **Phase A independent validation:** evaluate group-macro reward/goal rank Kendall and top-1, regression MAE/Huber on original units, direct-relative sign accuracy, reward/task conflict cases, terrain/goal support and uncertainty calibration. Evaluate per-group outcomes and confidence intervals over groups, never over 147 correlated pairs. Freeze numeric pass thresholds and model/weight selection rule **before** new validation outcomes are inspected. Current seven train groups cannot set these thresholds by optimization.
6. **Phase B auxiliary ablations:** only after Phase A's independent gate, compare primary-only, terminal-value, residual and combined variants against DEM-only, DEM+Path, portable-body and optional fixed anchor-latent baselines. Reject an auxiliary branch if primary ranking or calibration worsens. Do not let auxiliary Critic agreement substitute for task progress or measured reward.
7. **Selector gate:** on separate held-out support, test lexicographic selection, conflict handling, missing/OOD abstention and uncertainty fallback against direct and primary-only choices. Report realized task and locomotion outcomes, verified failures and censoring. No weighted scalar or Safety head can be deployed from these seven groups.

Candidate preference, model architecture, loss weights, thresholds and split membership must be frozen prospectively with additional independent training and validation data. The current contract supplies only smoke defaults and data-schema checks.
