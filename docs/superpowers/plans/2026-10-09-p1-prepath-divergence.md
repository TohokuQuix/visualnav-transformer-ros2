Scope: candidate-free evidence only. Preserve the golden and v1/v2 sealed roots, all numeric gates, and production follower. The golden and within-batch questions are separate.

1. **Static audit.** Verify all three source seals. Extract the four P1 source tiles, 28 target tile plans, frozen reset/prephysics states, v2 fixtures, settled traces and scene geometry/material config. Distinguish exact saved values, regenerated values and unavailable state. Produce a source/target field table and geometry provenance matrix. If a decisive prephysics mismatch or unobservable required state is found, stop before physics.
2. **Terrain reconstruction.** If static files cannot establish tile mesh identity, build a separate candidate-free generator probe. Freeze source, config, input manifest, metric definitions and resource caps before launch. Regenerate the two original 112-tile source terrains and the 112-tile mixed scene without stepping physics. Canonicalize per-tile mesh vertices/faces in tile-local coordinates, record placement transforms and material/collision configuration, and compare reconstructed source whole-scene SHA with the golden stage SHA. A mismatch leaves historical mesh identity unresolved.
3. **Earliest state probe.** Only if Phase A cannot settle the cause and required source state has a valid measurement alternative, instrument the smallest representative source/target and one direct triplicate. Capture reset, post-placement/prephysics and every physics step through the first divergence; sample DEM/Actor only at their actual update points. Pin the source and output root before execution. Compare numerical differences and frozen-gate crossings separately.
4. **Causal test.** Change one factor per probe, chosen from evidence: tile translation, scene size, a missing dynamic-state field, terrain mesh or observation noise. Avoid large 112-env repetition unless minimal experiments cannot reproduce the failure. Do not inject golden live observations.
5. **Decision and seal.** Report H1-H5, golden reproducibility, direct-clone reproducibility, first divergence step/magnitude, unresolved limits and next action. Save atomic SHA ledger and seal; commit only the new diagnostic code and small report. No Path, rollout, Outcome or training.
